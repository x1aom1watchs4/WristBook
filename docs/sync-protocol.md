# Протокол синхронизации (черновик)

Телефон — основной источник библиотеки и текста. Часы получают выбранную книгу, небольшой фрагмент текста и позицию чтения.

Предлагаемая запись прогресса:
```json
{
  "bookId": "stable-book-id",
  "chapter": 0,
  "offset": 1200,
  "updatedAt": "2026-01-01T12:00:00Z"
}
```

Реальный транспорт (BLE, локальная сеть или официальный companion API) нужно выбрать после подтверждения возможностей Xiaomi Watch S4 и доступного SDK. В текущей версии синхронизация описана, но ещё не реализована.
