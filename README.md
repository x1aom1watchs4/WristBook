# WristBook Watch prototype

Здесь лежит отдельная часть того же проекта для часов на базе Xiaomi Vela.
Это исходный прототип: он не является RPK и сам по себе не устанавливается на Xiaomi Watch S4.
Перед сборкой нужно сверить API и структуру с версией официального Vela SDK, доступной для целевого устройства.
